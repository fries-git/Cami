Server settings

Defaults point at the production servers (cami.barfpile.dev / images.barfpile.dev / chat.barfpile.dev). Pointing at a different setup, like a local dev server or another tunnel? All three must use matching schemes — https / wss together, or http / ws together — since a page loaded over https can't call plain http or ws endpoints; browsers block that silently. Pasting an http(s) link into the WebSocket field is fine, it's converted to ws/wss automatically. Changing these while logged in reconnects the socket.
